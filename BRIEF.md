### 2. TranquiBot — Autonomous Vehicle
- **Role:** Project Lead
- **Date:** Jan 2024 – Present
- **Tag:** Robotics / Perception
- **One-liner:** A Jetson Nano-based autonomous platform fusing depth, LiDAR, and GPS with LLM-driven high-level decisions.
- **What I built:**
  - Embedded architecture: Jetson Nano + OAK-D depth + LD06 LiDAR + Point One Fusion Engine GPS

  - Autonomy: ChatGPT API for high-level decisions, ROS2/Python middleware, VESC motor control
- **Outcome:** Real-time autonomous navigation from multimodal sensor inputs.
- **Image folder (existing repo):** `/images/AutoCar/`
