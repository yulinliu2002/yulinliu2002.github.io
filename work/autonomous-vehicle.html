TranquiBot

A Jetson Nano-based autonomous platform fusing depth, LiDAR, and GPS with LLM-driven high-level decisions.

01 — ContextA research-grade test bed, not a single-task vehicle.

TranquiBot was built to fuse multiple sensor modalities and put a large language model inside the autonomy loop — not for one specific task, but as a flexible platform for perception and decision-making experiments. The hardware is generic enough to repurpose; the value is in how the layers talk to each other.

02 — ConstraintsEdge compute, multimodal fusion, and LLMs in the loop.

Everything runs on a Jetson Nano. That means real-time fusion across LiDAR, depth, and GPS at edge throughput — and an LLM whose latency has to fit inside a control loop the platform can still react with.

03 — What I BuiltStack from sensors to high-level decisions.

  • Embedded architecture: Jetson Nano + OAK-D depth + LD06 LiDAR + Point One Fusion Engine GPS.
  • Stack: ROS2 + DonkeyCar framework.
  • Perception: OpenCV + TensorFlow inference for lane detection and waypoint generation.
  • Autonomy: ChatGPT API for high-level decisions, ROS2/Python middleware, VESC motor control.

04 — OutcomeEnd-to-end autonomy on multimodal sensor inputs.

The platform performs real-time autonomous navigation, drawing on every sensor in the stack and routing high-level decisions through the LLM layer.
